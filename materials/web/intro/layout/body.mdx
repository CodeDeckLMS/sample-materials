## この教材の目標

Flexboxの折り返しでカードを並べ、読む順序を保ったまま狭幅へ対応します。目安は35分です。

### 横に並べるだけでは終わらない

display: flexは子要素の並べ方を指定します。flex-wrap: wrapを付けると、収まらない要素を次の行へ送れます。gapなら、要素の間隔を一か所で設定できます。
例のflex: 1 1 14remは、空きに応じて伸縮し、14remを基準の大きさにします。長いファイル名やURLがあるときは、min-widthや折り返しの指定も確認します。

### 順番と操作を保つ

見た目のorderだけを変えると、キーボードの移動順や読み上げ順が見た目とずれることがあります。重要な内容をHTMLでも先に置き、まずその順番で自然に並ぶようにします。
広い画面だけで完成とせず、320px、文字200%、長い見出しを含む状態で試すのが大切です。

### 例を読み、結果を予想する

~~~css
.cards { display: flex; flex-wrap: wrap; gap: 1rem; }
.cards > article { flex: 1 1 14rem; min-width: 0; overflow-wrap: anywhere; }
~~~

## 手を動かして確かめる

1. 3枚のarticleをcardsクラスの親要素で囲みます。
2. 例のCSSを適用し、ウィンドウを狭めて折り返しを観察します。
3. 1枚に長い題名を入れ、横方向にページ全体がはみ出さないか調べます。
4. 各カードにリンクを入れ、Tabで移動した順序と見た目を比較します。
