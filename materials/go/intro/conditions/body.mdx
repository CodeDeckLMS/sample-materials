## この教材の目標

比較演算とifを使い、境界値の前後を確かめます。目安は30分です。

### 言葉の条件を式にする

「10以上20以下」は10と20の両方を含みます。Goでは value >= 10 && value <= 20 と書けます。&&は両方の条件が成り立つ場合、||は少なくとも一方が成り立つ場合に真になります。
10と20の間に入らない値を調べるなら value < 10 || value > 20 です。記号だけを入れ替えるのではなく、具体的な値を代入して確かめます。

### 境界の周りを試す

範囲の中央だけでは、>=と>の間違いを発見できません。9、10、20、21の4つを使うと、両端を含むかどうかを確かめられます。
Goのifの条件に括弧は必須ではありませんが、処理のブロックには波括弧を使います。読みやすく字下げを揃えましょう。

### 例を読み、結果を予想する

~~~go
package main

import "fmt"

func main() {
    value := 10
    if value >= 10 && value <= 20 {
        fmt.Println("Inside")
    } else {
        fmt.Println("Outside")
    }
}
~~~

## 手を動かして確かめる

1. 例のvalueを9、10、20、21へ変え、出力を表にします。
2. 条件を「10以上20未満」へ変更して、20の出力だけが変わるか確認します。
3. &&を||にすると何が起きるか、まず紙で予想します。
4. 2条件の一方だけが成り立つ入力を、自分で2つ作ってください。
