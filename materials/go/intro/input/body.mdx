## この教材の目標

Goのプログラムの入口を確認し、整数を2つ読み取って計算します。前提は標準入力の基本です。目安は30分です。

### mainから処理が始まる

実行するGoプログラムはpackage mainとmain関数を持ちます。fmtパッケージのScanは空白や改行で区切られた入力を読み取り、Printlnは値と改行を出力します。
例では幅4、高さ6に対して面積24を求めます。Scanへ渡す &width は、読み取った値を格納する変数の場所を表します。まずはこの形を使い、ポインターの詳しい仕組みは後の学習で扱います。

### 入出力の約束を守る

採点問題では「幅を入力してください」といった案内も出力の一部になります。要求された答えだけを出すことが大切です。負の数を受け付けるかどうかも、問題の制約で確認します。
入力を読み取れなければ処理を終えます。初期値の0で計算を続けるより、失敗した場所を確認できる形にしましょう。

### 例を読み、結果を予想する

~~~go
package main

import "fmt"

func main() {
    var width, height int
    if _, err := fmt.Scan(&width, &height); err != nil {
        return
    }
    fmt.Println(width * height)
}
~~~

## 手を動かして確かめる

1. 例の入力4 6で実行し、24になることを確認します。
2. 入力1 8、7 7の出力を予想してから確かめます。
3. 掛け算を足し算に変えて、結果がどう違うか説明します。
4. 関連問題「タイルの面積」では、初期コードの計算部分を自分で埋めて提出します。
