## この教材の目標

forでN個の入力を読み、条件に合う個数を集計します。目安は35分です。

### 回数と値の合計を分ける

例では、0以上の値を見つけるたびにcountを1増やします。count += valueでは値の合計になり、求めている「個数」と違う結果になります。
forの初期化は1回、条件は各回の処理前、更新は各回の後に行います。indexを0から始め、index < sizeとすると、size回繰り返します。

### 集計変数の初期化は外に置く

countをループの内側で毎回0にすると、前の回までの個数が失われます。入力を読むvalueはその回だけに使うので内側、集計するcountは全体で使うので外側と、役割で置き場所を決めます。
最後に1回だけ答えを出すため、Printlnもループの外へ置きます。

### 例を読み、結果を予想する

~~~go
package main

import "fmt"

func main() {
    var size int
    fmt.Scan(&size)
    count := 0
    for index := 0; index < size; index++ {
        var value int
        fmt.Scan(&value)
        if value >= 0 {
            count++
        }
    }
    fmt.Println(count)
}
~~~

## 手を動かして確かめる

1. 入力「5 -2 0 7 -1 4」で、各回のcountを書き出します。
2. 0も数えているか、入力が1個の場合でも確認します。
3. すべて負、すべて0以上の入力を作り、予想と比べます。
4. 関連問題「非負の測定値」へ、自分で書いた集計処理を提出します。
