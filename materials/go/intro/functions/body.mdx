## この教材の目標

関数へ役割を分け、成功したかどうかを値と一緒に返します。目安は35分です。

### 1つの関数に1つの役割を持たせる

例のaverageは、渡された数列の平均を計算します。画面への出力はmainが担当します。計算と表示を分けると、別の入力でも同じ関数を試しやすくなります。
valuesが空のときは分母が0になるため、計算せずfalseを返します。結果が0である場合と、計算できなかった場合を区別するため、数値だけでなくboolも返しています。

### 呼び出す側で結果を確認する

averageの戻り値を受け取ったら、okを見てから結果を使います。Goの標準ライブラリには、成否をerrorで返す関数も多くあります。err != nilを確認するのも、失敗を無視しないための同じ考え方です。
エラーのときに適当な値で計算を続けず、「どこまで分かっていて、どこから不明なのか」を明示しましょう。

### 例を読み、結果を予想する

~~~go
package main

import "fmt"

func average(values []int) (float64, bool) {
    if len(values) == 0 {
        return 0, false
    }
    total := 0
    for _, value := range values {
        total += value
    }
    return float64(total) / float64(len(values)), true
}

func main() {
    fmt.Println(average([]int{3, 5, 10}))
    fmt.Println(average([]int{}))
}
~~~

## 手を動かして確かめる

1. 例の戻り値を予想し、空の入力がfalseになることを確認します。
2. `[]int{0, 0}`を渡して、平均0と失敗が区別されることを確かめます。
3. 引数を変えても、mainの出力部分を変更せずに試せるか確認します。
4. 入力失敗を確認する最初の教材と、今回のokの役割を比べてください。
