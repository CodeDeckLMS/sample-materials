## この教材の目標

スライスへ値を保存し、前の値と比べる処理を書きます。添字の範囲を確認します。目安は35分です。

### 添字は0から始まる

valuesの長さが4なら、有効な添字は0、1、2、3です。values[4]を参照すると範囲外です。最後の位置はlen(values)-1であり、長さそのものではありません。
前の値と比べる処理はindexを1から始めます。0から始めるとindex-1が-1になり、前の要素は存在しません。

### 「増えた回数」を数える

3、5、5、9という列なら、3から5、5から9の2回増えています。同じ値は増加に含めない約束なので>を使い、>=にはしません。
要素が1個なら隣り合う組がなく、答えは0です。最小の入力を特別に壊さないよう、ループの開始位置と終了条件を一緒に確認します。

### 例を読み、結果を予想する

~~~go
package main

import "fmt"

func main() {
    values := []int{3, 5, 5, 9}
    increases := 0
    for index := 1; index < len(values); index++ {
        if values[index] > values[index-1] {
            increases++
        }
    }
    fmt.Println(increases)
}
~~~

## 手を動かして確かめる

1. 例を実行する前に、比較する添字の組をすべて書きます。
2. 全部同じ値、ずっと減る値、要素が1個のスライスで試します。
3. 条件を>=へ変えたとき、同じ値の列で違いが出ることを確認します。
4. 関連問題「測定値の増加回数」では、入力からスライスを作る部分も確認してください。
