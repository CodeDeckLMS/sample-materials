## この教材の目標

intとfloat64を使い分け、割り算の前後の型変換の違いを確かめます。目安は25分です。

### 値の種類を決める

型は扱う値と演算の規則を決めます。int同士の割り算は整数の結果になります。7 / 2の結果は3で、あとからfloat64へ変換しても、すでに取り除かれた小数部分は戻りません。
小数を求めるには、割る前に両方をfloat64へ変換します。例の2つの計算は見た目が似ていますが、型を変える順番が異なります。

### 単位も型とは別に考える

同じintでも、秒と分をそのまま足してはいけません。変数名に単位を入れると、計算の意味を確認しやすくなります。timeSecondsから分と余りの秒を求めるなら、60で割った商と余りを別々に使います。
0で割る入力は避け、どの値が分母になるのかを入力条件と照らし合わせましょう。

### 例を読み、結果を予想する

~~~go
package main

import "fmt"

func main() {
    total, count := 7, 2
    fmt.Println(float64(total / count))
    fmt.Println(float64(total) / float64(count))
}
~~~

## 手を動かして確かめる

1. 7を8へ変え、2つの式の結果が同じになる理由を考えます。
2. 7を9、2を4へ変えて、変換の順序による違いを確かめます。
3. 125秒を、商と余りを使って2分5秒へ分けるコードを書きます。
4. 秒の余りが0になる入力も1つ作ってください。
